The caret package (Kuhn et al., 2024) is a package that focuses on streamlining the process of creating predictive models. It focuses on machine learning applications and we will use it to help us with logistic regression.

Data

Today we will look at the Titanic dataset. This dataset contains information about the passengers on the Titanic.

dat <- rio::import("https://fabio-setti.netlify.app/data/Titanic-Dataset.csv")

Predicting Survival: Linear Regression?

The Survived variable denoted whether a passenger survived the Titanic wreck. let’s say that we think that whether someone survived or not may be related to how much they spent on their Titanic ticket, Fare. we can run linear regression and get some results:

lin_reg <- lm(Survived ~ Fare, dat)
summary(lin_reg)

However, Survived is a binary variable, where only 2 outcome are possible (0 = died, 1 = survived). Here are the counts:

table(dat$Survived)

  0   1 
549 342


You can probably intuit that a linear regression is not appropriate for a binary DV, but looking at a plot will make many of the reasons clear.

Plotting the regression

Plot Code 
ggplot(dat, aes(x = Fare, y = Survived)) +
  geom_point() +
  geom_smooth(method = "lm", se = FALSE)
